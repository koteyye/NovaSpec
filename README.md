# NovaSpec2

**NovaSpec** - Flutter/Dart версия приложения для создания технических заданий с ИИ-ассистентом.

## 🚀 Обзор проекта

NovaSpec - это современное Flutter приложение для создания и управления техническими заданиями с помощью искусственного интеллекта. Приложение следует MVVM архитектуре с использованием Provider для управления состоянием и обеспечивает поддержку русского и английского языков.

## ✨ Ключевые особенности

### 🏗️ Архитектура
- **MVVM паттерн** с четким разделением ответственности
- **Provider** для реактивного управления состоянием
- **Dependency Injection** через GetIt
- **Feature-based** структура проекта

### 🎨 Пользовательский интерфейс
- **Material Design 3** с темной/светлой темой
- **Адаптивный дизайн** для разных размеров экранов
- **Кастомные компоненты** с TypeScript референс стилем
- **Плавные анимации** и переходы

### 🌐 Локализация
- **Русский и английский** языки
- **Динамическое переключение** без перезапуска
- **Поддержка кириллицы** через шрифт Inter

### 🔧 Функциональность
- **Управление проектами** и техническими заданиями
- **AI ассистент** для помощи в создании спецификаций
- **Проводник файлов** с поддержкой различных форматов
- **Настройки приложения** с сохранением конфигурации
- **WebView интеграция** для Swagger UI
- **Monaco Editor** для редактирования кода

### 🛡️ Безопасность и производительность
- **Валидация входных данных** с защитой от атак
- **Кэширование** для оптимизации производительности
- **Ленивая загрузка** экранов и компонентов
- **Обработка ошибок** для всех граничных случаев
- **Безопасное хранение** конфиденциальных данных

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd NovaSpec2
```

### 2. Установка зависимостей
```bash
flutter pub get
```

### 3. Кодогенерация
```bash
flutter packages pub run build_runner build
```

### 4. Запуск приложения
```bash
# Для Windows
flutter run -d windows

# Для macOS
flutter run -d macos

# Для Linux
flutter run -d linux

# Для мобильных устройств
flutter run
```
