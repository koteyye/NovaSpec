# Требования к иконке системного трея

## Назначение
Иконка используется для отображения NovaSpec в системном трее во время фоновой работы музикации.

## Требования

### Формат
- **Формат**: PNG
- **Размер**: 32x32 пикселя (основной), можно также добавить 16x16 и 48x48
- **Цветовая схема**: Прозрачный фон, работает на светлом и темном фоне

### Внешний вид
- **Стиль**: Минималистичный, современный
- **Элементы**: Должна содержать музыкальную ноту или нотный символ
- **Цвета**: Основной цвет - синий или фиолетовый (#3B82F6 или #8B5CF6)
- **Альтернативный вариант**: Может содержать логотип "N" (от NovaSpec) с музыкальным элементом

### Состояния (опционально)
Можно создать несколько вариантов для разных состояний:
- **Обычное состояние**: Стандартная иконка
- **Активное состояние**: Ярче или с небольшим свечением
- **Завершено**: Зеленая галочка или нотка
- **Ошибка**: Красный восклицательный знак

## Пример дизайна

### Вариант 1: Музыкальная нота
- Простая стилизованная нота
- Синий цвет на прозрачном фоне
- Легкая тень для глубины

### Вариант 2: Нота с буквой N
- Буква "N" стилизованная под ноту
- Градиент из синего в фиолетовый
- Современный плоский дизайн

## Размещение
Файл должен быть сохранен как:
```
assets/icons/tray/tray_icon.png
```

## Инструменты для создания
- Adobe Illustrator
- Figma
- Inkscape (бесплатный)
- Canva
- Любой графический редактор с поддержкой PNG

## Проверка
После создания иконки:
1. Убедитесь, что она хорошо видна на светлом и темном фоне
2. Проверьте читаемость в маленьком размере
3. Убедитесь, что прозрачность работает корректно
4. Тестируйте на разных ОС (Windows, macOS, Linux)
