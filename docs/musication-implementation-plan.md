# План реализации функционала музикации

## Обзор задачи
Реализация функционала музикации в приложении NovaSpec через сервис gen-api.ru с интеграцией AI-ассистента для генерации текстов песен.

## Этапы реализации

### Этап 1: Подготовительные требования

#### 1.1 Выбор AI модели для генерации Lyrics
**Что нужно сделать:**
- Добавить в заглушку AI-ассистента поле для выбора модели
- Реализовать получение списка моделей через API
- Сохранение выбранной модели в конфигурации

**Технические детали:**
- Запрос моделей для всех провайдеров кроме antropic: `POST ${baseURL}/openai/v1/models`
- Запрос моделей для antropic: `POST ${baseURL}/v1/models`
- Скроллинг списка если более 10 моделей
- Сохранение модели в конфигурации приложения

#### 1.2 Настройка мока gen-api.ru
**Что нужно сделать:**
- Добавить в debug меню чек-бокс "Мок gen-api.ru"
- Добавить текстовое поле для URL мока (по умолчанию http://localhost:8080)
- Реализовать переключение между реальным и мок сервисом

### Этап 2: Индикатор музикации

#### 2.1 Получение реального баланса
**Что нужно сделать:**
- Заменить хардкодный баланс (150 р) на реальный из API
- Реализовать запрос к `/user` endpoint

**Технические детали:**
```dart
final response = await dio.get(
  'https://api.gen-api.ru/api/v1/user',
  options: Options(
    headers: {
      'Authorization': 'Bearer $token',
      'User-Agent': 'NovaSpec/1.0',
    },
  ),
);
```

#### 2.2 Обновление баланса
Баланс обновляется в следующих случаях:
- При проверке подключения в настройках
- При сохранении настроек
- По клику на иконку "Обновить" в индикаторе
- После завершения цикла музикации

### Этап 3: Кнопка "Музикация"

#### 3.1 Размещение кнопки
**Что нужно сделать:**
- Добавить иконку "Музикация" в bar открытого файла
- Расположить после кнопки "Редактор"
- Отображать только для файлов .md и .html
- Дизейблить если не выбрана AI-модель

### Этап 4: Генерация Lyrics

#### 4.1 Запрос к AI-провайдеру
**Что нужно сделать:**
- Реализовать запрос к выбранному AI-провайдеру и модели
- Учесть особенности разных провайдеров (Z-AI baseURL)

**Технические детали:**
```dart
final response = await dio.post(
  '${baseURL}/v1/chat/completions',
  options: Options(
    headers: {
      'Authorization': 'Bearer $apiKey',
      'Accept-Language': 'en-US,en',

    },

  data: {
    'model': selectedModel,

ТЗ, на основе которого нужно сгенерировать Lyrics: ${contentFromFile}
'''
      }
    ],
    'stream': true
  },

```

### Этап 5: Генерация песни через gen-api.ru

#### 5.1 Запрос на генерацию
**Что нужно сделать:**
- Реализовать POST запрос к gen-api.ru
- Обработать различные коды ответов

**Технические детали:**
```dart
final response = await dio.post(
  'https://api.gen-api.ru/api/v1/networks/suno',
  options: Options(
    headers: {
      'Authorization': 'Bearer $token',
      'Content-Type': 'application/json',
    },
  ),
  data: {
    'title': '${uuid.v4()}',
    'tags': genreFromConfig,
    'prompt': lyricsFromAI,
    'translate_input': false,
    'model': 'v5',
  },
);
```

#### 5.2 Обработка кодов ответов
- **200/201**: Сохранить request_id, начать опрос статуса
- **402**: Недостаточно средств
- **400**: Запрос не найден
- **401**: Проблемы с токеном
- **404**: Несуществующая нейросеть
- **503**: Непредвиденная ошибка
- **419**: Слишком много запросов

#### 5.3 Опрос статуса генерации
**Что нужно сделать:**
- Реализовать Timer.periodic для опроса каждые 2 секунды
- Остановить опрос при статусе "success"

**Технические детали:**
```dart
final response = await dio.get(
  'https://api.gen-api.ru/api/v1/request/get/$requestId',
  options: Options(
    headers: {'Authorization': 'Bearer $token'},
  ),
);
```

## Тестирование

### Сценарии тестирования:
1. Выбор AI модели в ассистенте
2. Переключение на мок-сервис
3. Обновление баланса
4. Генерация музикации для .md файла
5. Генерация музикации для .html файла
6. Обработка ошибок (недостаточно средств, неверный токен)
7. Graceful shutdown при закрытии приложения
8. Восстановление процесса после перезапуска

### Мок-сервис для тестирования:
- Endpoint: http://localhost:8080
- Должен имитировать ответы gen-api.ru
- Поддерживать все статусы генерации

## Примечания

- Все текстовые элементы должны использовать локализацию
- Не использовать тосты (кроме graceful shutdown)
- Следовать существующей архитектуре приложения
- Использовать существующие UI компоненты (ModernButton, ModernToast)
- Все запросы должны обрабатываться через dio
- Состояние должно управляться через Provider
