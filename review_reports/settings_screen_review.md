# Отчет о ревью NovaSpec после исправлений

Зацени, братан. Провел полное ревью проекта после исправлений и нашел несколько косяков, которые нужно поправить.

## 🔴 Критические проблемы

### 1. Неправильная иконка Confluence
**Проблема**: В [`_buildConfluenceIndicator`](lib/features/topbar/widgets/top_bar.dart:256) используется стандартная иконка `Icons.cloud` вместо требуемой `assets/images/atlassian-icon.svg`.

**Решение**: Заменить `Icons.cloud` на `SvgPicture.asset('assets/images/atlassian-icon.svg', width: 16, height: 16)`.

### 2. "Светофор" macOS на Windows
**Проблема**: В [`TopBar`](lib/features/topbar/widgets/top_bar.dart:50-61) есть условие `if (Theme.of(context).platform != TargetPlatform.macOS)`, которое добавляет "светофор" для всех платформ кроме macOS, но на Windows это не должно отображаться.

**Решение**: Изменить условие на `if (Theme.of(context).platform == TargetPlatform.macOS)` или полностью убрать "светофор" для Windows.

### 3. МНОГО ХАРДКОДНОГО ТЕКСТА (КРИТИЧЕСКОЕ НАРУШЕНИЕ)
**Проблема**: Во всем приложении используется хардкодный русский текст вместо локализации:

**TopBar:**
- `'Файл'` (строка 127)
- `'Настройки'` (строка 161)
- `'О программе'` (строка 192)
- `'Новый проект'` (строка 384)
- `'Открыть'` (строка 403)
- `'Сохранить'` (строка 423)
- `'Выход'` (строка 463)

**SettingsDialogContent:**
- `'Base URL'` (строка 105)
- `'Confluence URL'` (строка 172)
- `'Email'` (строка 182)
- `'Confluence Token'` (строка 192)
- `'API Key'` (строка 224)
- `'Music Genre'` (строка 235)

**MainScreen:**
- `'Нет открытого проекта'` (строка 201)
- `'Рабочее пространство'` (строка 289)

**Решение**: Заменить весь хардкодный текст на вызовы `AppLocalizations.of(context)`. Например:
```dart
Text(AppLocalizations.of(context)!.file)
```

### 4. Отсутствие переключателя темы в настройках
**Проблема**: В [`SettingsDialogContent`](lib/features/settings/widgets/settings_dialog_content.dart) нет переключателя темы, хотя в [`GeneralTab`](lib/features/settings/widgets/general_tab.dart:72-85) он есть, но не используется в диалоге настроек.

**Решение**: Добавить переключатель темы в [`SettingsDialogContent`] или интегрировать [`GeneralTab`] в диалог настроек.

## 🟡 Менее критичные проблемы

### 5. Расположение элементов в top_bar
**Проблема**: Файл, настройки и о программе находятся справа (что соответствует требованиям), но могут быть проблемы с выравниванием на разных размерах экрана.

**Решение**: Проверить адаптивность для разных размеров экрана.

### 6. Функциональность переключения темы
**Проблема**: Метод [`updateTheme`](lib/core/providers/app_provider.dart:143) реализован, но не вызывается из основных настроек.

**Решение**: Убедиться, что переключатель темы правильно вызывает `appProvider.updateTheme(theme)`.
