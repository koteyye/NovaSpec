## Краткое описание

Анализ существующего TypeScript UI проекта nova-spec-ide-studio-main и создание основы для миграции на Flutter/Dart. Включает полный анализ компонентов, настройку Flutter проекта и создание документации по миграции в соответствии с требованиями NovaSpec.

## Технический контекст

**Язык/Версия**: Dart 3.x с Flutter 3.x  
**Основные зависимости**: dio, shared_preferences, file_picker, monaco_editor, webview_flutter, flutter_svg, flutter_localizations  
**Хранение**: SharedPreferences (настройки), flutter_secure_storage (токены), файловая система (проекты)  
**Тестирование**: Только ручное тестирование через UI (запрещены автоматические тесты)  
**Целевая платформа**: Desktop (Windows, macOS, Linux)  
**Цели производительности**: Быстрый запуск проекта, эффективная работа с файлами  
**Ограничения**: Визуальная идентичность с TypeScript референсом, использование только Flutter экосистемы  
**Масштаб/Объем**: Анализ всего UI проекта, создание полной документации миграции
