# Research: Обновление 006 - Корректировка Z.AI и редизайн Top Bar

**Date**: 2025-10-26  
**Feature**: Корректировка существующей Z.AI реализации и редизайн Top Bar  
**Status**: Complete

## Решения по исследованию

### Z.AI Корректировка

**Decision**: Исправить существующую некорректную реализацию Z.AI в AI провайдерах  
**Rationale**: Z.AI уже добавлен в список провайдеров, но работает неправильно - неверный эндпоинт валидации и неполная логика  
**Alternatives considered**: 
- Полная переработка Z.AI интеграции (избыточно, т.к. основа уже есть)
- Создание отдельной конфигурации для Z.AI (нарушает единую архитектуру AI провайдеров)

**Technical Findings**:

1. **Проблема в валидации**: Текущий эндпоинт `/api/v1/user` неверный (используется в ai_validation_service.dart)
2. **Правильные эндпоинты**:
   - Coding Plan: `https://api.z.ai/api/coding/paas/v4/models`
   - API (Pay-as-you-go): `https://api.z.ai/api/paas/v4/models`
3. **Неполная логика**: Нет динамического обновления base URL при смене типа доступа в settings_provider.dart
4. **Отсутствует UI**: Z.AI не добавлен в UI настройки AI провайдера (только в settings_dialog_content.dart)

### Top Bar Редизайн

**Decision**: Обновить существующий Top Bar для соответствия TypeScript референсу  
**Rationale**: Текущая реализация в top_bar.dart не соответствует визуальному дизайну референса  
**Alternatives considered**:
- Минимальные изменения (недостаточно для соответствия)
- Полная замена компонента (избыточно, т.к. основа уже есть)

**Technical Findings**:

1. **Расположение кнопок**: В референсе кнопки слева, индикаторы справа (текущая реализация отличается)
2. **Меню**: Выпадающие меню для "Файл" и "Настройки" (нужно исправить логику)
3. **Индикаторы**: AI провайдер, Confluence, Музикация с правильным оформлением
4. **Платформенные особенности**: Светофор только для macOS (уже реализовано правильно)

### Архитектурные решения

**Decision**: Исправлять существующую архитектуру с Provider и Widget композицией  
**Rationale**: Z.AI уже интегрирован в архитектуру, нужно только исправить ошибки  
**Alternatives considered**: Bloc/Riverpod (требуют переписывания существующего кода)

## Common Pitfalls

### Ошибки в Z.AI:
- ❌ Использование старого эндпоинта `/api/v1/user` (в ai_validation_service.dart)
- ✅ Использовать `/user` с правильным base URL
- ❌ Неправильная логика определения base URL (в settings_provider.dart)
- ✅ Переиспользовать существующую AI конфигурацию с добавлением `zaiAccessType`
- ❌ Отсутствует UI для выбора типа доступа Z.AI
- ✅ Добавить поля в существующий UI настроек AI провайдера

### Ошибки в Top Bar:
- ❌ Неправильное расположение элементов
- ✅ Кнопки слева, индикаторы справа
- ❌ Использование стандартных Flutter кнопок
- ✅ Использовать созданные компоненты

## Риски и митигация

- **API изменения Z.AI**: Использовать абстракцию в сервисах
- **Визуальные несоответствия**: Точное следование TypeScript референсу
