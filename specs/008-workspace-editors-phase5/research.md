# Исследование: Workspace and Editors Phase 5.1

**Дата**: 2025-10-26  
**Статус**: Завершено

## Monaco Editor интеграция

**Решение**: Использование пакета `monaco_editor` для Flutter  
**Обоснование**: Пакет предоставляет полноценную интеграцию Monaco Editor в Flutter приложения с поддержкой синтаксической подсветки, автодополнения и тем  
**Альтернативы рассмотрены**: 
- `flutter_code_editor` - ограниченная функциональность
- `code_field` - менее стабильный
- Собственная реализация через WebView - сложнее в поддержке

## WebView для Swagger UI

**Решение**: Использование `webview_flutter` с локальным HTML файлом Swagger UI  
**Обоснование**: Позволяет отображать OpenAPI спецификации в интерактивном интерфейсе Swagger UI  
**Альтернативы рассмотрены**:
- Рендеринг YAML/JSON как текст - менее функционально
- Внешний Swagger UI - требует интернет соединения

## Определение текстовых файлов

**Решение**: Использование расширений файлов и проверки MIME типа  
**Обоснование**: Надежное определение текстовых файлов для открытия в Monaco Editor  
**Список текстовых расширений**: .txt, .js, .ts, .dart, .py, .java, .cpp, .c, .h, .css, .scss, .json, .yaml, .yml, .xml, .sql, .sh, .bat, .md, .html

## Обработка больших файлов

**Решение**: Асинхронная загрузка с прогресс-индикатором для файлов >10MB  
**Обоснование**: Предотвращение блокировки UI при открытии больших файлов  
**Реализация**: Stream чтение файла с обновлением прогресса

## Копирование рендеренного контента

**Решение**: Использование `flutter_html` для получения HTML и `flutter_markdown` для преобразования в HTML  
**Обоснование**: Позволяет копировать отформатированный контент со стилями  
**Альтернативы**: Копирование сырого исходного кода - не соответствует требованиям

## Минимальные размеры окна

**Решение**: Минимальная ширина 1200px, высота 800px  
**Обоснование**: Обеспечивает достаточное пространство для трехпанельной компоновки  
**Источник**: Анализ TypeScript референса и тесты на различных экранах

## Управление состоянием вкладок

**Решение**: Provider с ChangeNotifier для управления состоянием вкладок  
**Обоснование**: Соответствует конституции проекта, обеспечивает реактивное обновление UI  
**Сохранение состояния**: SharedPreferences для восстановления между сессиями

## Контекстное меню

**Решение**: Кастомный виджет с позиционированием относительно курсора  
**Обоснование**: Полный контроль над внешним видом и поведением  
**Альтернативы**: `flutter_context_menu` - меньше кастомизации

## Файловые операции

**Решение**: Использование `dart:io` для локальных файловых операций  
**Обоснование**: Нативная поддержка Flutter для работы с файловой системой  
**Безопасность**: Проверка путей и разрешений перед операциями

## Производительность рендеринга

**Решение**: Ленивая загрузка контента вкладок и кэширование  
**Обоснование**: Оптимизация производительности при большом количестве открытых вкладок  
**Кэширование**: In-memory кэш для отрендеренного контента
