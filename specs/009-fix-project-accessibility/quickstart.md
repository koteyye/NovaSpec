# Quickstart Guide: Fix Project Accessibility Error

**Feature**: 009-fix-project-accessibility  
**Version**: 1.0.0  
**Date**: 2025-10-29

## Overview

Это руководство поможет быстро начать работу с исправленной системой доступности проектов. Основные изменения:
- Устранены ложные уведомления для папок-проектов
- Введен постоянный мониторинг вместо периодических проверок
- Добавлена синхронизация между экземплярами приложения

## Быстрый старт

### 1. Открытие проекта

#### Папочный проект
```
1. Файл → Открыть проект
2. Выбрать папку проекта
3. Система автоматически определит тип проекта
4. Откроется проводник с файлами проекта
```

#### Файловый проект
```
1. Файл → Открыть проект
2. Выбрать файл проекта (.novaspec)
3. Откроется редактор с файлом проекта
```

### 2. Мониторинг доступности

#### Автоматический мониторинг
- **Папочные проекты**: Мониторинг включен автоматически, уведомления не показываются
- **Файловые проекты**: Проверка каждые 30 секунд, уведомления только при реальных проблемах

#### Ручная проверка
```
1. Правый клик по проекту в дереве
2. "Проверить доступность"
3. Результат показывается в статус-баре
```

### 3. Работа с несколькими экземплярами

#### Синхронизация изменений
```
1. Открыть один проект в двух экземплярах NovaSpec
2. Внести изменения в первом экземпляре
3. Изменения автоматически появятся во втором
4. Статус синхронизации показывается в заголовке окна
```

#### Блокировка проекта
```
- При редактировании файлы блокируются для других экземпляров
- Блокировка автоматически снимается при сохранении
```

## Основные сценарии использования

### Сценарий 1: Работа с папочным проектом

```
1. Создать новую папку для проекта
2. Открыть её как проект в NovaSpec
3. Работать с файлами без уведомлений о доступности
4. Все изменения сохраняются автоматически
5. Проект остается доступным все время
```

**Результат**: Никаких ложных уведомлений, комфортная работа.

### Сценарий 2: Работа с файловым проектом

```
1. Создать файл проекта .novaspec
2. Открыть его в NovaSpec
3. Система проверяет доступность каждые 30 секунд
4. При реальных проблемах показывает уведомление
5. Статус проекта виден в заголовке окна
```

**Результат**: Надежный мониторинг без ложных срабатываний.

### Сценарий 3: Совместная работа

```
1. Открыть проект на общем диске
2. Запустить NovaSpec на двух компьютерах
3. Вносить изменения в одном экземпляре
4. Изменения синхронизируются в реальном времени
5. Конфликты решаются автоматически
```

**Результат**: Бесшовная совместная работа над проектом.

## Устранение проблем

### Проблема: "Проект недоступен"

#### Возможные причины:
1. **Папка удалена**: Проверьте существование папки проекта
2. **Нет прав**: Убедитесь в наличии прав на чтение/запись
3. **Сетевой путь**: Сетевые папки не поддерживаются

#### Решение:
```
1. Проверить путь к проекту
2. Убедиться что папка существует
3. Проверить права доступа
4. Переместить проект на локальный диск
```

### Проблема: "Не удалось синхронизировать"

#### Возможные причины:
1. **Проект заблокирован**: Другой экземпляр редактирует файлы
2. **Нет прав на запись**: Недостаточно прав для создания lock-файлов
3. **Сетевые проблемы**: Проблемы с доступом к общему ресурсу

#### Решение:
```
1. Закрыть другие экземпляры NovaSpec
2. Проверить права на запись в папку проекта
3. Перезапустить приложение
```

### Проблема: "Мониторинг не работает"

#### Возможные причины:
1. **Слишком много файлов**: Система ограничивает мониторинг больших проектов
2. **Системные ограничения**: Превышен лимит файловых дескрипторов
3. **Антивирус**: Блокирует мониторинг файловой системы

#### Решение:
```
1. Добавить проект в исключения антивируса
2. Уменьшить количество файлов в проекте
3. Перезапустить приложение с правами администратора
```

## Настройки

### Настройки мониторинга

```
Файл → Настройки → Проекты

- Включить мониторинг: [✓]
- Интервал проверки файлов: 30 секунд
- Игнорировать файлы: *.tmp, *.lock, .git/*
- Синхронизация между экземплярами: [✓]
```

### Настройки уведомлений

```
Файл → Настройки → Уведомления

- Показывать ошибки доступности: [✓]
- Показывать синхронизацию: [✓]
- Автоматически скрывать через: 5 секунд
```

## Советы по эффективности

### Для папочных проектов
- Используйте .gitignore для исключения временных файлов
- Структурируйте проект логически
- Избегайте слишком глубоких вложений папок

### Для файловых проектов
- Регулярно сохраняйте изменения
- Создавайте резервные копии
- Используйте контроль версий

### Для совместной работы
- Согласуйте время работы с коллегами
- Используйте комментарии для важных изменений
- Проверяйте статус синхронизации перед закрытием

## Диагностика

### Проверка статуса проекта
```
1. Вид → Статус проекта
2. Выбрать проект из списка
3. Просмотреть детальную информацию:
   - Тип проекта
   - Путь к проекту
   - Статус доступности
   - Активный мониторинг
   - Синхронизация
```

### Логирование
```
Файл → Показать логи

- Последние события мониторинга
- Ошибки синхронизации
- Изменения статуса проекта
```

## Поддержка

Если проблема не решена:
1. Проверьте логи приложения
2. Попробуйте переоткрыть проект
3. Перезапустите приложение
4. Обратитесь в техподдержку с описанием проблемы

---

**Важно**: Эта функция устраняет проблему ложных уведомлений о доступности проектов. Если вы все еще видите такие уведомления, убедитесь что используете последнюю версию приложения.
