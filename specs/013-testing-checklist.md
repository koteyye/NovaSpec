# Чеклист тестирования задачи 013-webview2-swagger

**Версия:** 1.0  
**Дата:** 2024  
**Цель:** Проверка исправлений утечки ресурсов HTTP сервера и корректности работы Swagger UI

---

## 🎯 Основные сценарии тестирования

### ✅ Сценарий 1: Одиночное открытие файла
**Цель:** Проверить базовую функциональность

1. Открыть проект в NovaSpec
2. Открыть один Swagger/OpenAPI файл (`.json` или `.yaml`)
3. Дождаться загрузки Swagger UI
4. Проверить в консоли сообщение: `Swagger server started on http://localhost:XXXX`
5. Проверить, что интерфейс загрузился корректно
6. Закрыть вкладку
7. Проверить в консоли: `SwaggerServer reference count decreased to 0`
8. Проверить в консоли: `No more references, stopping server...`

**Ожидаемый результат:** ✅ Сервер запустился и остановился без ошибок

---

### ✅ Сценарий 2: Множественное открытие файлов
**Цель:** Проверить работу системы подсчёта ссылок

1. Открыть первый Swagger файл
2. Проверить в консоли: `SwaggerServer reference count increased to 1`
3. Открыть второй Swagger файл (можно тот же самый)
4. Проверить в консоли: `SwaggerServer reference count increased to 2`
5. Открыть третий Swagger файл
6. Проверить в консоли: `SwaggerServer reference count increased to 3`
7. Закрыть первую вкладку
8. Проверить: `SwaggerServer reference count decreased to 2`
9. Проверить: сервер НЕ остановился (другие вкладки работают)
10. Закрыть вторую вкладку
11. Проверить: `SwaggerServer reference count decreased to 1`
12. Закрыть третью вкладку
13. Проверить: `SwaggerServer reference count decreased to 0`
14. Проверить: `No more references, stopping server...`

**Ожидаемый результат:** ✅ Сервер остановился только после закрытия всех вкладок

---

### ✅ Сценарий 3: Быстрое переключение вкладок
**Цель:** Проверить отсутствие race conditions

1. Открыть Swagger файл
2. Сразу закрыть вкладку (не дожидаясь полной загрузки)
3. Снова открыть тот же файл
4. Повторить шаги 2-3 несколько раз подряд
5. Дождаться загрузки одной из вкладок
6. Проверить консоль на наличие ошибок

**Ожидаемый результат:** ✅ Никаких ошибок с портами, файл загружается корректно

---

### ✅ Сценарий 4: Повторное открытие после закрытия
**Цель:** Проверить корректное освобождение порта

1. Открыть Swagger файл
2. Дождаться загрузки
3. Закрыть вкладку
4. Подождать 1 секунду (для освобождения порта ОС)
5. Снова открыть тот же файл
6. Проверить консоль: НЕ должно быть ошибок типа "port already in use"

**Ожидаемый результат:** ✅ Файл открывается без ошибок

---

### ✅ Сценарий 5: Windows без WebView2 (Fallback режим)
**Цель:** Проверить режим открытия в браузере

1. На Windows без WebView2 открыть Swagger файл
2. Проверить, что отображается кнопка "Открыть в браузере"
3. Нажать на кнопку
4. Проверить, что браузер открылся с корректным URL
5. Проверить, что Swagger UI загрузился в браузере

**Ожидаемый результат:** ✅ Swagger UI открывается во внешнем браузере

---

### ✅ Сценарий 6: Windows с WebView2
**Цель:** Проверить нативную интеграцию WebView2

1. На Windows с установленным WebView2 открыть Swagger файл
2. Проверить, что Swagger UI загружается внутри приложения
3. Проверить базовые операции: скролл, раскрытие эндпоинтов
4. Закрыть вкладку

**Ожидаемый результат:** ✅ Swagger UI работает внутри приложения

## 🔍 Проверка логов

### Правильная последовательность логов при открытии:
```
=== SWAGGER VIEWER SIMPLE INIT ===
FilePath: /path/to/swagger.json
SwaggerServer reference count increased to 1
=== LOAD OPENAPI SPEC ===
File path: /path/to/swagger.json
Starting new server or loading new spec...
Swagger server started on http://localhost:8080
Server running on: http://localhost:8080
OpenAPI spec loaded successfully
```

### Правильная последовательность логов при закрытии:
```
SwaggerServer reference count decreased to 1
SwaggerServer reference count decreased to 0
No more references, stopping server...
Stopping Swagger server on port 8080...
Server stopped successfully
```

## ❌ Критические ошибки (НЕ должны появляться)

### 1. Ошибка занятого порта:
```
SocketException: Failed to create server socket (OS Error: The shared flag to bind() 
needs to be `true` if binding multiple times on the same (address, port) combination.), 
address = localhost, port = 8080
```
**Статус:** ✅ ИСПРАВЛЕНО

### 2. Ошибка остановки активного сервера:
```
Cannot stop server: 2 active references remaining
```
**Примечание:** Это не ошибка, а защитный механизм (правильное поведение)

## 🛠️ Команды для проверки портов

### Windows (PowerShell):
```powershell
# Проверить, какие порты заняты
netstat -ano | findstr :8080

# Убить процесс по PID (если нужно)
taskkill /PID <PID> /F
```

### Linux/Mac:
```bash
# Проверить, какие порты заняты
lsof -i :8080

# Убить процесс
kill -9 <PID>
```

## 🐛 Известные ограничения

1. **Задержка освобождения порта:** После закрытия последней вкладки порт освобождается через ~200ms
2. **WebView2 на Windows:** Требуется установленный WebView2 Runtime
3. **Одновременная загрузка:** Все вкладки используют один HTTP сервер
