# Тестирование функциональности настроек

## Проблема
При каждом открытии настроек происходило сбрасывание текущих значений.

## Причины
1. **AppProvider регистрировался как factory** - каждый вызов sl<AppProvider>() создавал новый экземпляр
2. **Кэш не инвалидировался** при сохранении конфигурации
3. **Отсутствие проверки загрузки** конфигурации перед обновлением

## Решения
1. ✅ **Изменен DI registration**: AppProvider теперь singleton (registerLazySingleton)
2. ✅ **Добавлена инвалидация кэша**: CacheService.remove() после сохранения
3. ✅ **Добавлена проверка конфигурации**: автоматическая перезагрузка при null

## Тест-кейс
1. Открыть настройки
2. Изменить тему на dark
3. Закрыть настройки
4. Открыть настройки снова
5. Проверить, что тема осталась dark

## Ожидаемый результат
Настройки сохраняются между открытиями экрана настроек.
